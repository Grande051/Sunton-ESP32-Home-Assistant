### 3D Printed Case

The 3D enclosure is based on the original [Sunton ESP32 8048S070 Display Case](https://www.printables.com/model/1487606-sunton-esp32-8048s070-display-case/files) available on Printables.

**Modifications made:**
- Added ventilation openings to improve airflow and heat dissipation.
- Adapted the enclosure for my personal ESP32-S3 dashboard project.

Original model credits and license are retained according to the original author's licensing terms.
