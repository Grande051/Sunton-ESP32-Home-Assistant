# Sunton ESP32-S3 7" — Modified 3D Printed Case

This enclosure is a modified version of the original [ESP32-8048S070 N/C Case](https://www.printables.com/model/350263-esp32-8048s070-nc-case), available on Printables.

## Modifications Made

- Added ventilation openings to improve airflow and heat dissipation.
- Adapted the enclosure for my personal Sunton ESP32-S3 7-inch Home Assistant dashboard.
- Provided the modified model in 3MF format for 3D printing.
